0. ANTES DE EMPEZAR - donde NO instalarlo
-------------------------------------------------------------------------------

NO lo pongas en el Escritorio si OneDrive lo sincroniza (en tu otra PC, SI lo
sincroniza). La base de perfiles es SQLite en modo WAL: son tres archivos que
solo valen juntos, y OneDrive los sube cuando le toca. Asi se corrompe.

Usa una ruta local y corta, por ejemplo:   C:\dev\camoufox

Corta tambien importa: Windows corta las rutas a 260 caracteres y el bundle de
la interfaz tiene nombres largos y anidados.

OJO CON LA VERSION DE PYTHON. Tiene que ser 3.13 o anterior. Con 3.14 la
instalacion falla: uv.lock fija una version de numpy que no publica wheel para
3.14, asi que uv intenta compilarlo, no puede, y el entorno se queda VACIO --
la app arranca con "No module named 'uvicorn'" o parecido. install.py ya lo
comprueba y se para antes de descargar nada.

Y no uses `uv python install` para conseguir una version buena: los Python que
uv descarga no estan firmados por la PSF, y Smart App Control los bloquea.
Bajalo de python.org.

2. CLONAR Y PREPARAR
-------------------------------------------------------------------------------

  mkdir C:\dev
  cd C:\dev
  git clone https://github.com/iamrocan/camoufox-profile-manager.git camoufox
  cd camoufox

NO uses --depth 1 aqui. Para desarrollar quieres el historial completo
(git log, git blame, poder volver atras).

Instala uv y las dependencias:

  python -m pip install --upgrade uv
  uv sync --extra dev --extra desktop
  .venv\Scripts\camoufox fetch

El extra "dev" trae pytest, ruff y mypy. El extra "desktop" trae pywebview, que
es lo que da la ventana propia en vez de una pestana del navegador.

Si te dice que "uv" no se reconoce, cierra la terminal y abre una nueva: el
instalador lo pone en el PATH y las terminales ya abiertas no se enteran.

OJO: si algun dia corres install.py en esta carpeta, vuelve a sincronizar con
--extra dev, porque install.py sincroniza solo con --extra desktop y eso
DESINSTALA pytest.


SI "uv sync" FALLA CON "os error 396"

El mensaje dice: "La operacion de nube no se puede realizar en un archivo con
vinculos permanentes incompatibles". uv crea vinculos permanentes desde su
cache para no guardar dos veces la misma wheel, y un cliente de sincronizacion
en la nube no sabe representarlos. Anade --link-mode=copy:

  uv sync --extra dev --extra desktop --link-mode=copy

Y OJO: ese error significa que ALGO esta sincronizando esa carpeta. Eso es
peligroso por si mismo -- lee el punto 0 -- y install.py no lo detecto, porque
mira las variables de entorno y los nombres de carpeta de los clientes de
sincronizacion, no el sistema de archivos. Comprueba si de verdad lo esta:

  (Get-Item "C:\Camoufox Persistente").Attributes
  $env:OneDrive

Si los atributos incluyen ReparsePoint, Offline o RecallOnDataAccess, esa
carpeta esta sincronizada y la base de perfiles corre peligro. Muevela.

7. LAS CUATRO TRAMPAS QUE CUESTAN TIEMPO
-------------------------------------------------------------------------------

(a) SI CAMBIAS LA INTERFAZ, HAY QUE RECOMPILAR

    El bundle compilado (src/camoufox_pm/webui/) se commitea a proposito, para
    que instalar no necesite Node. Si editas algo en web/src y no recompilas,
    publicas una interfaz SIN tu cambio.

      cd web
      npx tsc --noEmit -p tsconfig.json
      npx eslint src
      cd ..
      python scripts\build_webui.py
      git add src/camoufox_pm/webui

(b) SI CAMBIAS PYTHON, HAY QUE REINICIAR LA APP

    Los archivos de la interfaz se leen del disco en cada peticion, asi que un
    manager abierto sirve la pagina NUEVA con el Python VIEJO. La pagina llama a
    una ruta que el proceso viejo no conoce y falla.

    El error te lo dice: "the running server is older than the page: restart the
    manager". Cierra la app y vuelve a abrirla.

    Si el acceso directo parece no hacer nada, suele ser un proceso anterior
    ocupando el puerto 8000. Esto lo despeja:

      Get-Process | Where-Object { $_.ProcessName -like '*camoufox*' } | Stop-Process -Force

(c) NUNCA ESCRIBAS CODIGO CON Set-Content DE POWERSHELL

    Convierte UTF-8 dos veces y destroza acentos, guiones largos y puntos
    suspensivos. Ya corrompio un archivo fuente una vez. Usa un editor, o Python
    con encoding="utf-8" explicito.

    Para detectar el dano:   grep -c "â€" archivo.tsx


(d) SI WINDOWS DICE "part of this app has been blocked"

    Es Smart App Control de Windows 11, no la app. camoufox-pm.exe y
    camoufox.exe no los distribuye nadie: pip y uv los FABRICAN en tu maquina a
    partir de un stub, asi que son binarios sin firmar y sin reputacion, que es
    justo lo que SAC veta (eventos CodeIntegrity 3033/3077/3118). El python.exe
    y el pythonw.exe del mismo venv SI estan firmados por la Python Software
    Foundation y SAC los permite.

    Por eso nada de este repositorio llama a esos .exe. Si tu acceso directo
    viene de una version antigua de install.py, repuntalo:

      python install.py --shortcut-only

    Y desde consola, en vez del nombre corto:

      .venv\Scripts\python.exe -m camoufox_pm.cli --desktop

    Comprobar si SAC esta encendido (0 apagado, 1 bloqueando, 2 evaluando):

      (Get-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Control\CI\Policy').VerifiedAndReputablePolicyState

    NO lo apagues para salir del paso: una vez apagado no se puede reencender
    sin reinstalar Windows, y la via firmada no te cuesta nada.

    Ojo: SAC decide por reputacion en la nube, no por el archivo. Puede permitir
    algo un dia y bloquearlo al siguiente sin que tu cambies nada.

10. NOTA SOBRE PowerShell
-------------------------------------------------------------------------------

En PowerShell "curl" NO es curl: es un alias de Invoke-WebRequest y no entiende
